# 🌍 Qloo-vibe

**Qloo-vibe** is a production-ready, ultra-modern, glassmorphic cultural intelligence dashboard built specifically for the Qloo Agentic Hackathon. It maps cross-domain connections across music, movies, fashion, dining, and travel using Qloo's Taste AI™ engine.

---

## ✨ Key Features

- **Glassmorphic UI:** Features a striking Yellow logo, dynamic source indicators, and dual themes (Deep Navy Blue Dark Mode / Soft Light Purple Light Mode).
- **3-Tab Architecture:**
  1. **Input:** Seed entity search, category selection, audience segments (Gen-Z, Luxury, etc.), and intensity/diversity sliders.
  2. **Output:** 10 advanced features including an interactive 3D Taste Graph, AI Persona generator, Affinity Heatmap, Cultural DNA Radar Chart, Vibe Preview Player, and Executive PDF/JSON Exporter.
  3. **Favorites Manager:** Bookmarking system to save and organize top cultural matches.
- **Global Accessibility:** Instantly translate the entire UI into 15 different languages using the top-bar language switcher.
- **Smart Fallback Engine:** Seamlessly switches between live Qloo API endpoints (`https://hackathon.api.qloo.com`) and a robust mock data engine for zero-downtime demonstrations.

---

## 🚀 How to Use

1. **Open the App:** Access the live web URL in any modern browser.
2. **Enter a Seed:** Go to the **Input** tab, type any artist, movie, or brand, select your parameters, and click analyze.
3. **Explore Intelligence:** View the comprehensive multi-dimensional results in the **Output** tab, export reports, or save your favorites!
